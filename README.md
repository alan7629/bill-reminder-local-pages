# BillReminder-Local — public information pages

Public-facing description and privacy policy for an independently operated personal Windows desktop bill-reminder utility.

This repository holds only static HTML and CSS for GitHub Pages. It is deliberately **separate** from the private software repository, and has no bill data, source mail, OAuth tokens, financial documents, passwords, tracking scripts, or backend.

- Homepage: index.html
- Privacy policy: privacy.html
- Styling: style.css
