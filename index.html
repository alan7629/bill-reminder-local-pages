BillReminder-Local 是個人 Windows 桌面帳單提醒工具。經使用者授權後，從 Gmail 讀取電子帳單通知及相關 PDF，在本機核對應繳金額和日期，再於使用者自己的 Google 日曆建立提醒。

這不是銀行或付款服務。工具不會登入網路銀行、移轉資金或代替使用者繳款；資訊不確定時會標記「待核對」。此工具與 Google 或任何銀行均無隸屬關係。

主要功能

讀取電子帳單

透過 Gmail 唯讀授權篩選可能的銀行、電信和生活帳單，並在本機處理可讀取的 PDF 附件。

核對金額與期限

使用文字、表格座標及必要的本機 OCR 核實繳款資訊。加密失敗或資料不足時改列待核對，不憑空推算。

建立日曆提醒

在使用者擁有的 Google 日曆建立私人事項，通常於截止前三天提醒；確認已存在的事項後避免重複。

如何運作

  1. 使用者在自己的 Windows 電腦安裝工具，透過 Google OAuth 授權 Gmail 唯讀與本人日曆活動管理。
  2. 程式篩選帳單信件、讀取附件，在本機核實金額和期限；PDF 開啟密碼使用 Windows DPAPI 保護。
  3. 對可確認的帳單新增日曆提醒；對缺失資料、逾期、疑似自動扣款或需要網站驗證者，保留人工核對。

部分金融機構的網頁帳單需要使用者親自完成人機驗證，再匯入下載的 PDF；工具不繞過 CAPTCHA。

使用條款與限制

本工具僅供私人管理帳單提醒使用，依現況提供，無法保證郵件、銀行 PDF 格式、日期辨識或 Google API 持續可用。付款義務、是否已扣款及正確截止日，均應以銀行或帳單發行機構正式紀錄為準。

使用者自行決定是否授權 Google 資料存取，並可隨時撤銷授權。本工具不提供金融建議、不代表任何銀行，也不負責執行付款。
